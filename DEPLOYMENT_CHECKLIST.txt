================================================================================
POWER MONITOR - DEPLOYMENT CHECKLIST
================================================================================

Use this checklist to ensure proper installation and configuration of the
Power Monitor system for 24/7 operation.

================================================================================
PRE-DEPLOYMENT CHECKLIST
================================================================================

HARDWARE PREPARATION (RASPBERRY PI):
------------------------------------
□ Raspberry Pi 3/4 or newer
□ Power supply (5V, 2.5A minimum)
□ MicroSD card (16GB minimum, Class 10)
□ Raspberry Pi OS installed and updated
□ Network connection (Ethernet or WiFi)
□ GPIO pins accessible
□ Optocouplers (if using high voltage signals)
□ Wiring and connectors
□ Multimeter for testing

SOFTWARE REQUIREMENTS:
----------------------
□ Python 3.8 or higher installed
□ MySQL Server 5.7 or higher installed
□ pip package manager available
□ Git (optional, for cloning repository)
□ SSH access configured (for remote setup)

POWER SOURCE PREPARATION:
-------------------------
□ EB status signal available (3.3V logic or via optocoupler)
□ Generator 1 status signal available
□ Generator 2 status signal available
□ Common ground connection
□ Signal voltage verified (must be ≤ 3.3V)
□ Optocouplers tested (if using)

DATABASE PREPARATION:
---------------------
□ MySQL root password known
□ Database name decided (default: ebpc)
□ Database user created (or using root)
□ Network access configured (if remote DB)
□ Backup strategy planned

================================================================================
RASPBERRY PI INSTALLATION CHECKLIST
================================================================================

STEP 1: SYSTEM PREPARATION
---------------------------
□ Update system packages:
  sudo apt-get update && sudo apt-get upgrade -y

□ Install required system packages:
  sudo apt-get install python3-pip python3-tk mysql-server git -y

□ Verify Python version:
  python3 --version  (should be 3.8+)

□ Verify MySQL is running:
  sudo systemctl status mysql


STEP 2: PROJECT SETUP
----------------------
□ Copy project to Raspberry Pi:
  scp -r infac-p1 pi@raspberrypi.local:/home/pi/

□ Navigate to project directory:
  cd /home/pi/infac-p1

□ Verify all files present:
  ls -la

□ Make scripts executable:
  chmod +x install_service_linux.sh
  chmod +x run_monitor_service.py


STEP 3: PYTHON DEPENDENCIES
----------------------------
□ Install Python packages:
  pip3 install -r requirements.txt

□ Install RPi.GPIO:
  pip3 install RPi.GPIO

□ Verify installations:
  pip3 list | grep -E "(mysql|RPi.GPIO|matplotlib)"


STEP 4: DATABASE CONFIGURATION
-------------------------------
□ Secure MySQL installation:
  sudo mysql_secure_installation

□ Create database (if not auto-created):
  mysql -u root -p
  CREATE DATABASE ebpc;
  exit

□ Edit config.json with correct credentials:
  nano config.json
  
□ Test database connection:
  python3 -c "from src.db_reader import DatabaseReader; \
    db = DatabaseReader(); print('OK' if db.test_connection() else 'FAIL')"


STEP 5: GPIO WIRING
-------------------
□ Power off Raspberry Pi
□ Connect EB status to Pin 11 (GPIO 17)
□ Connect GEN1 status to Pin 13 (GPIO 27)
□ Connect GEN2 status to Pin 15 (GPIO 22)
□ Connect common ground to Pin 6 (GND)
□ Double-check all connections
□ Verify no shorts with multimeter
□ Power on Raspberry Pi


STEP 6: GPIO TESTING
--------------------
□ Test GPIO reading:
  python3 -m src.gpio_reader

□ Verify pin states displayed
□ Toggle power sources and verify readings change
□ Confirm debounce working (no false triggers)
□ Press Ctrl+C to stop test


STEP 7: SERVICE INSTALLATION
-----------------------------
□ Install as systemd service:
  sudo ./install_service_linux.sh

□ Verify service started:
  sudo systemctl status power-monitor

□ Check for any errors in output
□ Verify service enabled for auto-start:
  sudo systemctl is-enabled power-monitor


STEP 8: VERIFICATION
--------------------
□ View live logs:
  sudo journalctl -u power-monitor -f

□ Verify events being recorded:
  mysql -u root -p ebpc -e "SELECT COUNT(*) FROM events;"

□ Toggle power source and verify event recorded
□ Check log shows state changes
□ Verify no error messages


STEP 9: GUI TESTING (OPTIONAL)
-------------------------------
□ Open GUI application:
  python3 -m src.main

□ Verify dashboard shows current status
□ Check LED indicators match actual power states
□ Verify graphs display correctly
□ Test filters and search
□ Test CSV export
□ Close GUI


STEP 10: FINAL CHECKS
----------------------
□ Reboot Raspberry Pi:
  sudo reboot

□ After reboot, verify service auto-started:
  sudo systemctl status power-monitor

□ Check logs for clean startup:
  sudo journalctl -u power-monitor -n 50

□ Verify events still being recorded
□ Document installation date and time
□ Create initial database backup


================================================================================
WINDOWS INSTALLATION CHECKLIST
================================================================================

STEP 1: SYSTEM PREPARATION
---------------------------
□ Windows 10 or higher
□ Python 3.8+ installed
□ MySQL Server installed and running
□ Administrator access available
□ Antivirus configured to allow Python


STEP 2: PROJECT SETUP
----------------------
□ Copy project to Windows machine:
  C:\Program Files\PowerMonitor\

□ Open Command Prompt as Administrator
□ Navigate to project directory:
  cd "C:\Program Files\PowerMonitor"


STEP 3: DEPENDENCIES
--------------------
□ Install Python packages:
  pip install -r requirements.txt

□ Install Windows service support:
  pip install pywin32

□ Verify installations:
  pip list | findstr "mysql pywin32"


STEP 4: DATABASE CONFIGURATION
-------------------------------
□ Verify MySQL running:
  net start | findstr MySQL

□ Create database if needed
□ Edit config.json with credentials
□ Test database connection


STEP 5: SERVICE INSTALLATION
-----------------------------
□ Run installation script as Administrator:
  install_service_windows.bat

□ Verify service installed:
  sc query PowerMonitorService

□ Check service status shows "RUNNING"


STEP 6: VERIFICATION
--------------------
□ Check service.log for activity:
  type service.log

□ Verify events being recorded in database
□ Test GUI application
□ Verify auto-start after reboot

================================================================================
TROUBLESHOOTING CHECKLIST
================================================================================

IF SERVICE WON'T START:
-----------------------
□ Check logs: sudo journalctl -u power-monitor -xe
□ Verify MySQL running: sudo systemctl status mysql
□ Check config.json syntax: python3 -m json.tool config.json
□ Verify Python dependencies: pip3 list
□ Check file permissions: ls -la
□ Try manual run: python3 run_monitor_service.py


IF GPIO NOT READING:
--------------------
□ Test GPIO: python3 -m src.gpio_reader
□ Check wiring connections
□ Verify voltage levels with multimeter
□ Check user in gpio group: groups $USER
□ Verify RPi.GPIO installed: pip3 list | grep RPi.GPIO
□ Check for loose connections


IF DATABASE ERRORS:
-------------------
□ Test connection: mysql -u root -p
□ Verify credentials in config.json
□ Check MySQL status: sudo systemctl status mysql
□ Review MySQL error log: sudo tail /var/log/mysql/error.log
□ Verify database exists: SHOW DATABASES;
□ Check table structure: DESCRIBE events;


IF GUI WON'T START:
-------------------
□ Check Python version: python3 --version
□ Verify Tkinter: python3 -m tkinter
□ Check database connection
□ Review error messages
□ Try running from terminal for error output
