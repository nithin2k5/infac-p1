WHAT IS THIS?
================================================================================

This is a complete power monitoring system that:

✅ Monitors EB (Electricity Board) and Generator power status 24/7
✅ Reads status from Raspberry Pi GPIO pins in real-time
✅ Records all events to MySQL database with timestamps
✅ Provides a beautiful desktop GUI for viewing reports
✅ Runs as a background service (auto-starts on boot)
✅ Detects power outages and tracks durations
✅ Works on Raspberry Pi, Linux, and Windows

================================================================================
GPIO PIN CONNECTIONS (RASPBERRY PI)
================================================================================

Connect your power status signals to these pins:

    Pin 11 (GPIO 17) ← EB Power Status
    Pin 13 (GPIO 27) ← Generator 1 Status
    Pin 15 (GPIO 22) ← Generator 2 Status
    Pin 6  (GND)     ← Common Ground

Signal Logic:
  HIGH (3.3V) = Power ON
  LOW (0V)    = Power OFF

⚠️ IMPORTANT: Never connect more than 3.3V to GPIO pins!
   Use optocouplers for higher voltages.

See GPIO_WIRING.txt for detailed wiring diagrams.

  "database": {
    "host": "localhost",
    "user": "root",
    "password": "YOUR_PASSWORD_HERE",
    "database": "ebpc"
  }
}

The installation script will create the database automatically.

TESTING
================================================================================

Test GPIO Reading (Raspberry Pi):
----------------------------------
python3 -m src.gpio_reader

This shows real-time GPIO pin status. Toggle your power sources to verify.


Test Background Monitor:
------------------------
python3 run_monitor_service.py

Runs the monitor in foreground. Press Ctrl+C to stop.


Open GUI Dashboard:
-------------------
python3 -m src.main

Opens the desktop application with graphs and reports.
