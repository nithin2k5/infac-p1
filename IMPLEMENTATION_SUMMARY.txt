================================================================================
HOW TO USE
================================================================================

RASPBERRY PI INSTALLATION:
--------------------------
1. Copy project to Raspberry Pi
2. Run: sudo ./install_service_linux.sh
3. Service starts automatically and runs 24/7

WINDOWS INSTALLATION:
---------------------
1. Copy project to Windows machine
2. Run install_service_windows.bat as Administrator
3. Service starts automatically and runs 24/7

GPIO WIRING:
------------
Connect power status signals to:
- Pin 11 (GPIO 17) for EB
- Pin 13 (GPIO 27) for Generator 1
- Pin 15 (GPIO 22) for Generator 2
- Pin 6 (GND) for common ground

Signal: HIGH (3.3V) = ON, LOW (0V) = OFF

⚠️ Use optocouplers for voltages > 3.3V!
