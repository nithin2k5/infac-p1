================================================================================
           POWER MONITOR - CUSTOMER DEPLOYMENT GUIDE
================================================================================

This guide explains how to create and deploy the customer package.

================================================================================
OVERVIEW
================================================================================

You have 3 main tasks:
1. Build customer package (compiled, no source code)
2. Deploy to customer's Raspberry Pi
3. Customer configures MySQL easily

================================================================================
STEP 1: BUILD CUSTOMER PACKAGE
================================================================================

On your development machine (Mac):

    cd /Users/nithinkumark/Developer/python/infac-p1
    python3 build_customer_package.py

This creates:
    customer_package/power-monitor/

What's included:
    ✓ Compiled .pyc files (NO .py source code)
    ✓ Automatic installer (install.sh)
    ✓ MySQL configuration wizard
    ✓ WhatsApp setup guide
    ✓ Customer documentation
    ✓ Configuration templates

What's NOT included:
    ✗ Source code (.py files)
    ✗ Development files
    ✗ Your credentials
    ✗ Internal documentation

================================================================================
STEP 2: CREATE DISTRIBUTION ARCHIVE
================================================================================

    cd customer_package
    tar -czf power-monitor-installer.tar.gz power-monitor/

Send this file to your customer:
    power-monitor-installer.tar.gz

================================================================================
STEP 3: CUSTOMER INSTALLATION
================================================================================

Customer receives: power-monitor-installer.tar.gz

They do:

1. Extract:
   tar -xzf power-monitor-installer.tar.gz
   cd power-monitor

2. Install (ONE COMMAND):
   sudo ./install.sh

3. The installer automatically:
   ✓ Installs all dependencies
   ✓ Runs MySQL configuration wizard (interactive)
   ✓ Installs 24/7 service
   ✓ Creates desktop shortcut
   ✓ Sets up everything

4. Wire GPIO connections

5. Done! Double-click desktop icon to open GUI

================================================================================
WHATSAPP NOTIFICATIONS SETUP
================================================================================

Optional feature for customers who want notifications.

Customer needs:
1. Twilio account (free trial available)
2. WhatsApp-enabled phone number from Twilio

Setup steps for customer:

1. Get Twilio credentials from https://www.twilio.com

2. Create .env file:
   sudo nano /opt/power-monitor/.env

3. Add configuration:
   WHATSAPP_ENABLED=true
   WHATSAPP_PROVIDER=twilio
   TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   TWILIO_AUTH_TOKEN=your_auth_token_here
   TWILIO_FROM_NUMBER=whatsapp:+14155238886
   TWILIO_TO_NUMBER=whatsapp:+919876543210
   WHATSAPP_RATE_LIMIT_SECONDS=300

4. Restart service:
   sudo systemctl restart power-monitor

5. Test notification:
   python3 /opt/power-monitor/test_whatsapp.py

Notifications will be sent when:
- EB power goes OFF
- Generator turns ON (with interval time)
- Power is restored

Message format:
    🚨 Power Event Alert
    
    ⚡ Generator Activated: Generator 1 (GEN1)
    
    📅 Power Cut Started:
       2026-01-04 16:30:00
    
    🔄 Generator Started:
       2026-01-04 16:32:15
    
    ⏱️ INTERVAL TIME (Power Cut → Generator ON):
       2 minutes 15 seconds
       (135 seconds)
    
    Status: Generator is now active

================================================================================
UPDATING CUSTOMER INSTALLATIONS
================================================================================

When you release an update:

1. Build new package:
   python3 build_customer_package.py

2. Create new archive:
   tar -czf power-monitor-v1.1.tar.gz -C customer_package power-monitor/

3. Send to customer with update instructions:
   
   a. Stop service:
      sudo systemctl stop power-monitor
   
   b. Backup config:
      sudo cp /opt/power-monitor/config.json ~/config.backup
      sudo cp /opt/power-monitor/.env ~/env.backup (if exists)
   
   c. Extract new version:
      tar -xzf power-monitor-v1.1.tar.gz
      cd power-monitor
   
   d. Run installer:
      sudo ./install.sh
   
   e. Restore config:
      sudo cp ~/config.backup /opt/power-monitor/config.json
      sudo cp ~/env.backup /opt/power-monitor/.env (if exists)
   
   f. Restart service:
      sudo systemctl restart power-monitor
