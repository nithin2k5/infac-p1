1. RASPBERRY PI SETUP (WITH GPIO PINS)
================================================================================

The application is configured to read power status from GPIO pins:
  - GPIO 17 (Pin 11) → EB (Electricity Board) status
  - GPIO 27 (Pin 13) → Generator 1 status
  - GPIO 22 (Pin 15) → Generator 2 status

Pin Logic:
  - HIGH (3.3V) = Power ON
  - LOW (0V/GND) = Power OFF

Step-by-Step Installation:
--------------------------

1. Copy the project to Raspberry Pi:
   $ scp -r infac-p1 pi@raspberrypi.local:/home/pi/

2. SSH into Raspberry Pi:
   $ ssh pi@raspberrypi.local

3. Navigate to project directory:
   $ cd /home/pi/infac-p1

4. Install dependencies:
   $ sudo apt-get update
   $ sudo apt-get install python3-pip python3-tk mysql-server
   $ pip3 install -r requirements.txt
   $ pip3 install RPi.GPIO

5. Configure database in config.json:
   Edit config.json with your MySQL credentials

6. Test GPIO reading (optional):
   $ python3 -m src.gpio_reader
   This will show real-time GPIO pin status

7. Install as systemd service (runs 24/7):
   $ sudo ./install_service_linux.sh

8. Verify service is running:
   $ sudo systemctl status power-monitor

9. View live logs:
   $ sudo journalctl -u power-monitor -f

Service Management Commands:
---------------------------
- Start:   sudo systemctl start power-monitor
- Stop:    sudo systemctl stop power-monitor
- Restart: sudo systemctl restart power-monitor
- Status:  sudo systemctl status power-monitor
- Logs:    sudo journalctl -u power-monitor -f

The service will:
  ✓ Start automatically on boot
  ✓ Restart automatically if it crashes
  ✓ Monitor GPIO pins continuously
  ✓ Record all events to MySQL database

2. WINDOWS SETUP (AS A WINDOWS SERVICE)
================================================================================

For Windows machines, you can install the monitor as a Windows Service.

Prerequisites:
--------------
- Python 3.8 or higher installed
- MySQL server running
- Administrator privileges

Installation Steps:
-------------------

1. Open Command Prompt as Administrator:
   Right-click on Command Prompt → "Run as administrator"

2. Navigate to project directory:
   cd C:\path\to\infac-p1

3. Run the installation batch file:
   install_service_windows.bat

   This will:
   - Install required Python packages
   - Install pywin32 for Windows service support
   - Create and start the Windows service

4. Verify service is running:
   sc query PowerMonitorService

Service Management Commands:
---------------------------
- Start:   python install_windows_service.py start
- Stop:    python install_windows_service.py stop
- Restart: python install_windows_service.py restart
- Remove:  python install_windows_service.py remove
- Status:  sc query PowerMonitorService

View Service Logs:
------------------
Check the file: service.log in the project directory

Note: On Windows, GPIO reading is simulated since there's no actual GPIO hardware.
Use this for testing the UI and database functionality.

4. GPIO PIN WIRING GUIDE (RASPBERRY PI)
================================================================================

Physical Pin Layout:
--------------------
Connect your power status signals to these GPIO pins:

Pin 11 (GPIO 17) → EB Power Status
Pin 13 (GPIO 27) → Generator 1 Status
Pin 15 (GPIO 22) → Generator 2 Status
Pin 6  (GND)     → Common Ground

Wiring Instructions:
--------------------

Option A: Direct Connection (if your power source provides 3.3V logic)
----------------------------------------------------------------------
1. Connect EB status output → GPIO 17 (Pin 11)
2. Connect GEN1 status output → GPIO 27 (Pin 13)
3. Connect GEN2 status output → GPIO 22 (Pin 15)
4. Connect common ground → GND (Pin 6)

Option B: Using Optocouplers (recommended for safety)
-----------------------------------------------------
If your power sources provide higher voltages (5V, 12V, 24V, etc.),
use optocouplers to isolate and convert to 3.3V logic:

1. Use optocouplers (e.g., PC817) for each input
2. Input side: Connect to your power source status
3. Output side: Connect to GPIO pins (with appropriate resistors)
4. This provides electrical isolation and protection

Example Circuit (per input):
----------------------------
Power Source → [Resistor] → Optocoupler LED → GND
Optocoupler Transistor: Collector → 3.3V (Pin 1)
                       Emitter → GPIO Pin (17/27/22)

Signal Logic:
-------------
- When power is ON: GPIO pin reads HIGH (1)
- When power is OFF: GPIO pin reads LOW (0)

Safety Notes:
-------------
⚠️ NEVER connect voltages higher than 3.3V directly to GPIO pins!
⚠️ Use optocouplers for isolation when dealing with AC or high voltage
⚠️ Double-check all connections before powering on
⚠️ Consider using a fuse for additional protection

5. TESTING AND TROUBLESHOOTING
================================================================================

Test GPIO Reading:
------------------
$ python3 -m src.gpio_reader

This will show real-time status of all GPIO pins.
Toggle your power sources to verify correct reading.

Test Background Monitor:
------------------------
$ python3 run_monitor_service.py

This runs the monitor in foreground mode (not as service).
Press Ctrl+C to stop.

Test Database Connection:
--------------------------
$ python3 -c "from src.db_reader import DatabaseReader; \
  db = DatabaseReader(); print('Connected!' if db.test_connection() else 'Failed')"

View Logs:
----------
- Linux/Raspberry Pi: sudo journalctl -u power-monitor -f
- Windows: Check service.log file
- Manual run: Check monitor_service.log file

Common Issues:
--------------

1. "Permission denied" on GPIO:
   → Run with sudo or add user to gpio group:
     sudo usermod -a -G gpio $USER

2. "Module RPi.GPIO not found":
   → Install: pip3 install RPi.GPIO

3. Database connection failed:
   → Check MySQL is running: sudo systemctl status mysql
   → Verify credentials in config.json
   → Check firewall settings

4. Service won't start:
   → Check logs: sudo journalctl -u power-monitor -xe
   → Verify Python path in service file
   → Check file permissions

6. CREATING EXECUTABLE (.EXE) FOR WINDOWS
================================================================================

To create a standalone .exe file that can be installed on other Windows machines:

1. Install PyInstaller:
   pip install pyinstaller

2. Create the executable:
   pyinstaller --onefile --windowed --name="PowerMonitor" src/main.py

   For the GUI application:
   pyinstaller --onefile --windowed --name="PowerMonitorGUI" --icon=icon.ico src/main.py

   For the service:
   pyinstaller --onefile --name="PowerMonitorService" run_monitor_service.py

3. Find the .exe files in the 'dist' folder

4. Copy to target machine along with:
   - config.json
   - install_windows_service.py
   - install_service_windows.bat

5. On target machine:
   - Run install_service_windows.bat as Administrator
   - Or double-click PowerMonitorGUI.exe for GUI mode

Note: The .exe includes all dependencies except:
  - MySQL server (must be installed separately)
  - Python (not needed if using .exe)
