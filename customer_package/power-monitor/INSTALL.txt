================================================================================
                    POWER MONITOR - INSTALLATION GUIDE
================================================================================

This guide explains how to install the Power Monitor system like a professional
software package with both the 24/7 service and desktop GUI application.

================================================================================
QUICK INSTALLATION (ONE COMMAND)
================================================================================

On Raspberry Pi, run:

    sudo ./setup.sh

That's it! The installer will:
  ✓ Install all system dependencies
  ✓ Install Python packages
  ✓ Set up MySQL database
  ✓ Install 24/7 background service
  ✓ Create desktop shortcut for GUI
  ✓ Create application menu entry
  ✓ Set up command-line tools
  ✓ Configure permissions

Installation takes 5-10 minutes.

================================================================================
WHAT GETS INSTALLED
================================================================================

1. BACKGROUND SERVICE (24/7 Monitoring)
   ------------------------------------
   - Service name: power-monitor
   - Location: /etc/systemd/system/power-monitor.service
   - Auto-starts on boot: Yes
   - Monitors GPIO pins continuously
   - Records events to MySQL database
   - Logs to system journal

2. DESKTOP GUI APPLICATION
   ------------------------
   - Desktop shortcut: ~/Desktop/PowerMonitor.desktop
   - Menu entry: Accessories → Power Monitor
   - Opens status dashboard with:
     * Real-time LED indicators
     * Timeline graphs
     * Event reports
     * CSV export

3. COMMAND-LINE TOOLS
   -------------------
   - power-monitor        → Open GUI
   - power-monitor-logs   → View live service logs
   - power-monitor-status → Check service status

4. SYSTEM DEPENDENCIES
   --------------------
   - Python 3.8+
   - Tkinter (GUI support)
   - MySQL Server
   - RPi.GPIO
   - matplotlib

================================================================================
STEP-BY-STEP INSTALLATION
================================================================================

STEP 1: Transfer Files to Raspberry Pi
---------------------------------------
From your computer:

    scp -r power-monitor-rpi pi@raspberrypi.local:/home/pi/

Or use a USB drive to copy the folder.


STEP 2: SSH into Raspberry Pi
------------------------------
    ssh pi@raspberrypi.local


STEP 3: Navigate to Project
----------------------------
    cd power-monitor-rpi
    ls -la  # Verify files are present


STEP 4: Run Installer
----------------------
    sudo ./setup.sh

Follow the on-screen instructions.

⏱️ Installation takes 5-10 minutes.


STEP 5: Configure Database
---------------------------
After installation, edit config.json:

    nano config.json

Update the MySQL password:
    "password": "YOUR_MYSQL_PASSWORD_HERE"

Save: Ctrl+O, Enter
Exit: Ctrl+X


STEP 6: Wire GPIO Connections
------------------------------
⚠️ POWER OFF RASPBERRY PI FIRST!

    sudo shutdown -h now

Connect your power status signals:
    Pin 11 (GPIO 17) ← EB Power Status
    Pin 13 (GPIO 27) ← Generator 1 Status
    Pin 15 (GPIO 22) ← Generator 2 Status
    Pin 6  (GND)     ← Common Ground

Power on Raspberry Pi.


STEP 7: Restart Service
------------------------
After configuring database:

    sudo systemctl restart power-monitor


STEP 8: Verify Installation
----------------------------
Check service status:

    sudo systemctl status power-monitor

Should show: Active: active (running)

View logs:

    sudo journalctl -u power-monitor -f

Should show monitoring activity.


STEP 9: Open GUI
-----------------
Double-click "Power Monitor" icon on desktop

OR run:

    power-monitor

OR from menu:

    Menu → Accessories → Power Monitor

================================================================================
USING THE INSTALLED SYSTEM
================================================================================

OPENING THE GUI:
----------------
Method 1: Double-click desktop icon
Method 2: Menu → Accessories → Power Monitor
Method 3: Run command: power-monitor
Method 4: Run: python3 -m src.main


VIEWING SERVICE LOGS:
---------------------
    power-monitor-logs

OR:
    sudo journalctl -u power-monitor -f


CHECKING SERVICE STATUS:
------------------------
    power-monitor-status

OR:
    sudo systemctl status power-monitor


MANAGING THE SERVICE:
---------------------
Start:   sudo systemctl start power-monitor
Stop:    sudo systemctl stop power-monitor
Restart: sudo systemctl restart power-monitor
Disable: sudo systemctl disable power-monitor
Enable:  sudo systemctl enable power-monitor


ACCESSING DATABASE:
-------------------
    mysql -u root -p ebpc

View events:
    SELECT * FROM events ORDER BY timestamp DESC LIMIT 10;

================================================================================
WHAT RUNS WHERE
================================================================================

BACKGROUND SERVICE:
-------------------
- Runs: 24/7 automatically
- Location: System service (systemd)
- Logs: System journal (journalctl)
- Purpose: Monitor GPIO pins and record events
- Visibility: Invisible (background)
- Control: systemctl commands

DESKTOP GUI:
------------
- Runs: When you open it
- Location: Desktop shortcut / Menu
- Logs: Terminal output (if run from terminal)
- Purpose: View status, reports, and graphs
- Visibility: Window on screen
- Control: Open/close like any app

RELATIONSHIP:
-------------
Service (writes) → MySQL Database ← GUI (reads)

- Service monitors and writes events
- GUI reads and displays events
- Both use same database
- Independent of each other
- Can run together or separately

================================================================================
UNINSTALLATION
================================================================================

To completely remove the system:

    sudo systemctl stop power-monitor
    sudo systemctl disable power-monitor
    sudo rm /etc/systemd/system/power-monitor.service
    sudo systemctl daemon-reload
    rm ~/Desktop/PowerMonitor.desktop
    rm ~/.local/share/applications/power-monitor.desktop
    rm ~/.local/bin/power-monitor*

To remove database:

    mysql -u root -p -e "DROP DATABASE ebpc;"

To remove project files:

    rm -rf ~/power-monitor-rpi

================================================================================
TROUBLESHOOTING
================================================================================

INSTALLER FAILS:
----------------
- Check internet connection
- Run: sudo apt-get update
- Check disk space: df -h
- Check permissions: ls -la

SERVICE WON'T START:
--------------------
- Check logs: sudo journalctl -u power-monitor -xe
- Verify MySQL: sudo systemctl status mysql
- Check config.json syntax
- Test manually: python3 run_monitor_service.py

GUI WON'T OPEN:
---------------
- Check Tkinter: python3 -m tkinter
- Verify database connection
- Run from terminal to see errors
- Check config.json

GPIO NOT READING:
-----------------
- Test: python3 -m src.gpio_reader
- Check wiring connections
- Verify user in gpio group: groups
- Check RPi.GPIO: pip3 list | grep RPi

DATABASE ERRORS:
----------------
- Test connection: mysql -u root -p
- Check MySQL running: sudo systemctl status mysql
- Verify credentials in config.json
- Check database exists: SHOW DATABASES;

DESKTOP ICON NOT WORKING:
--------------------------
- Right-click icon → Properties
- Check "Allow executing file as program"
- Or run: chmod +x ~/Desktop/PowerMonitor.desktop

================================================================================
UPDATING THE SYSTEM
================================================================================

To update to a new version:

1. Stop service:
   sudo systemctl stop power-monitor

2. Backup config:
   cp config.json config.json.backup

3. Pull updates (if using git):
   git pull

4. Or copy new files over old ones

5. Restore config:
   cp config.json.backup config.json

6. Restart service:
   sudo systemctl restart power-monitor

7. Test GUI:
   power-monitor
