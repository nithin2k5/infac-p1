POWER MONITOR - QUICK START GUIDE
================================================================================

RASPBERRY PI SETUP (3 STEPS):
------------------------------

1. Install as service:
   $ sudo ./install_service_linux.sh

2. Check it's running:
   $ sudo systemctl status power-monitor

3. View live monitoring:
   $ sudo journalctl -u power-monitor -f

Done! The monitor is now running 24/7.


WINDOWS SETUP (2 STEPS):
-------------------------

1. Run as Administrator:
   install_service_windows.bat

2. Check service status:
   sc query PowerMonitorService

Done! The monitor is now running 24/7.


GPIO PIN CONNECTIONS (RASPBERRY PI):
-------------------------------------

Connect these pins on your Raspberry Pi:

  Pin 11 (GPIO 17) ← EB Power Status
  Pin 13 (GPIO 27) ← Generator 1 Status  
  Pin 15 (GPIO 22) ← Generator 2 Status
  Pin 6  (GND)     ← Common Ground

Signal: HIGH (3.3V) = ON, LOW (0V) = OFF

⚠️ WARNING: Never connect more than 3.3V to GPIO pins!
   Use optocouplers for higher voltages.


TEST GPIO READING:
------------------
$ python3 -m src.gpio_reader

This shows real-time pin status. Toggle power to verify.


VIEW GUI DASHBOARD:
-------------------
$ python3 -m src.main

Opens the monitoring dashboard with graphs and reports.


USEFUL COMMANDS:
----------------

Raspberry Pi/Linux:
  Start:   sudo systemctl start power-monitor
  Stop:    sudo systemctl stop power-monitor
  Restart: sudo systemctl restart power-monitor
  Logs:    sudo journalctl -u power-monitor -f

Windows:
  Start:   python install_windows_service.py start
  Stop:    python install_windows_service.py stop
  Logs:    Check service.log file


TROUBLESHOOTING:
----------------

Service won't start?
  → Check logs: sudo journalctl -u power-monitor -xe
  → Verify MySQL is running: sudo systemctl status mysql
  → Check config.json has correct database credentials

GPIO not reading?
  → Test: python3 -m src.gpio_reader
  → Check wiring connections
  → Verify 3.3V power supply

Database connection failed?
  → Check MySQL: sudo systemctl status mysql
  → Verify config.json credentials
  → Test: mysql -u root -p
