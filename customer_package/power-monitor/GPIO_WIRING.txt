PIN ASSIGNMENTS:
----------------
GPIO 17 (Physical Pin 11) → EB (Electricity Board) Status
GPIO 27 (Physical Pin 13) → Generator 1 Status
GPIO 22 (Physical Pin 15) → Generator 2 Status
GND     (Physical Pin 6)  → Common Ground

------------------------------------

    3.3V [ 1] [ 2] 5V

   GPIO4 [ 7] [ 8] GPIO14       │
     GND [ 9] [10] GPIO15       │

GPIO 27 [13] [14] GND     ←─────┼─── GEN1 Status
GPIO 22 [15] [16] GPIO23  ←─────┴─── GEN2 Status

WIRING CONNECTIONS:
-------------------

Option A: Direct 3.3V Logic Signals
------------------------------------
If your power monitoring circuit outputs 3.3V logic:

  EB Status Output    →  Pin 11 (GPIO 17)
  GEN1 Status Output  →  Pin 13 (GPIO 27)
  GEN2 Status Output  →  Pin 15 (GPIO 22)
  Common Ground       →  Pin 6  (GND)


Option B: Using Optocouplers (RECOMMENDED)
-------------------------------------------
For 5V, 12V, 24V, or AC signals, use optocouplers:

For EACH input (EB, GEN1, GEN2):

  Power Source Side:
  -----------------
  Status Signal → [Current Limiting Resistor] → Optocoupler LED (+)
  Optocoupler LED (-) → Power Source Ground

  Raspberry Pi Side:
  ------------------
  Pin 1 (3.3V) → Optocoupler Collector
  Optocoupler Emitter → GPIO Pin (17/27/22)
  Pin 6 (GND) → Common Ground


EXAMPLE: PC817 Optocoupler Circuit
-----------------------------------

For 12V DC Status Signal:

  12V Status ──[1kΩ]──┐
                      │
                   ┌──┴──┐
                   │ LED │  PC817
                   └──┬──┘
                      │
  12V GND ───────────┘

                   ┌──┬──┐
  3.3V (Pin 1) ────┤  C  │
                   │     │  PC817
  GPIO 17 (Pin 11)─┤  E  │
                   └─────┘

Repeat for GEN1 (GPIO 27) and GEN2 (GPIO 22).


RESISTOR VALUES:
----------------
Input voltage → Recommended resistor:
  3.3V  →  Not needed (direct connection)
  5V    →  220Ω - 470Ω
  12V   →  1kΩ - 2.2kΩ
  24V   →  2.2kΩ - 4.7kΩ

Formula: R = (V_in - 1.2V) / 20mA


SIGNAL LOGIC:
-------------
HIGH (3.3V on GPIO) = Power ON  (1)
LOW  (0V on GPIO)   = Power OFF (0)


TESTING:
--------
1. Connect wiring as shown above
2. Power on Raspberry Pi
3. Run test: python3 -m src.gpio_reader
4. Toggle power sources and verify readings


SAFETY WARNINGS:
----------------
⚠️ NEVER connect voltages > 3.3V directly to GPIO pins!
⚠️ NEVER connect AC voltage directly to GPIO pins!
⚠️ Always use current limiting resistors
⚠️ Use optocouplers for electrical isolation
⚠️ Double-check all connections before powering on
⚠️ Consider using a fuse for protection


TROUBLESHOOTING:
----------------

GPIO always reads LOW (0):
  → Check power source is ON
  → Verify wiring connections
  → Test voltage at GPIO pin (should be ~3.3V when ON)
  → Check optocoupler orientation

GPIO always reads HIGH (1):
  → Check for short circuit
  → Verify pull-down resistor configuration
  → Test with multimeter

Erratic readings:
  → Add debounce capacitor (0.1µF across GPIO and GND)
  → Check for loose connections
  → Verify power supply is stable
  → Increase debounce_time in code


ADVANCED: Multiple Generators
------------------------------
To monitor more than 2 generators, use additional GPIO pins:

  GPIO 23 (Pin 16) → Generator 3
  GPIO 24 (Pin 18) → Generator 4
  etc.

Update gpio_reader.py to add more pins to pin_config.
